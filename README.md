# Обозреватель технической документации

Платформа для работы с технической документацией телекоммуникационного оборудования:
полнотекстовый поиск с фасетной фильтрацией, древовидная навигация, чтение документов
с якорями по разделам и ассистент на основе искусственного интеллекта, который отвечает
только со ссылками на источники.

Правообладатель: ООО «Голибас Телеком». Разработано по техническому заданию
«Обозреватель технической документации» (Москва, 2026).

## Состав

| Часть | Технологии | Папка |
|---|---|---|
| Сервер API | Python 3.11+, FastAPI, SQLAlchemy, OpenSearch | `backend/` |
| Клиент | TypeScript, Next.js 14, React 18 | `frontend/` |
| Образцы документации | Markdown с метаданными | `sample-docs/` |
| Эксплуатационная документация | Markdown | `docs/` |
| Развёртывание | Docker, docker-compose, GitHub Actions | `docker-compose.yml`, `.github/` |

## Быстрый запуск

Полностью в Docker (OpenSearch + сервер + клиент):

```bash
cp .env.example .env
docker compose up -d --build
```

Клиент: http://localhost:3000, API и его описание OpenAPI: http://localhost:8000/api/docs-ui.
Первый зарегистрированный пользователь становится администратором.

Локально для разработки (без Docker, поиск в памяти процесса):

```bash
# сервер
cd backend
python -m venv .venv && . .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements-dev.txt
python -m app                                        # http://localhost:8000

# клиент
cd frontend
npm install
npm run dev                                          # http://localhost:3000
```

## Возможности

- **Документация**: дерево продукт → версия → домен → тема, переключение версии релиза,
  чтение документа с якорями по разделам, закреплённые разделы и сохранённые поиски
  в браузере, адаптивный макет для компьютера и телефона.
- **Поиск**: полнотекстовый поиск OpenSearch с фасетами product, vendor, domain, release,
  node_type, interface, protocol, topic; гибридное ранжирование с повторным ранжированием;
  запасной индекс в памяти, когда OpenSearch недоступен; повторные попытки при сбоях.
- **Пользователи**: регистрация, вход по логину и паролю, подтверждение по СМС-коду,
  вход по QR-коду, роли «пользователь» и «администратор», блокировка после неудачных
  попыток, автоматическое завершение сеанса через 30 минут без активности.
- **Ассистент**: режимы «объяснить», «сравнить», «диагностика»; ответы с привязкой
  к источникам и фрагментами документов; уровень уверенности; оценка «полезно / нет»;
  политика strict-required-citations — ответ без цитат блокируется.
- **Мониторинг и управление**: метрики, панели ошибок, задержек и пропускной способности,
  узкие места по стадиям, журнал административных действий, журнал ответов ИИ,
  переиндексация, режим обслуживания, корректный останов. Загрузка документов идемпотентна.

## Разработка

Ветки: `main` — стабильная версия, `develop` — разработка, `feature/*` — новые функции,
`bugfix/*` — исправления. Каждый push запускает сборку и тесты на Linux и Windows
(GitHub Actions), артефакты сборки сохраняются.

```bash
cd backend && ruff check app tests && pytest -q    # проверка стиля и тесты сервера
cd frontend && npm run typecheck && npm run build  # проверка типов и сборка клиента
```
