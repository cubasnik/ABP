# Интеграция eNodeB: интерфейс S1 и транспорт SCTP

## Назначение интерфейса S1
Интерфейс S1 соединяет eNodeB с опорной сетью EPC: плоскость управления S1-MME идёт к MME по протоколу S1AP поверх SCTP, плоскость пользователя S1-U — к SGW по GTP-U поверх UDP. Без установленной ассоциации SCTP базовая станция не может обслуживать абонентов.

## Параметры SCTP-профиля
Профиль SctpProfile задаёт поведение транспорта. Параметр rtoMin определяет минимальный таймаут повторной передачи в миллисекундах; значение по умолчанию 1000 мс, для каналов с задержкой более 100 мс рекомендуется 1500 мс. Параметр heartbeatInterval задаёт период проверки пути, по умолчанию 30000 мс. Параметр maxInitialRtx ограничивает число попыток установления ассоциации.

## Порядок настройки
1. Создать профиль SctpProfile с нужными rtoMin и heartbeatInterval.
2. Создать SctpEndpoint с локальным IP-адресом и портом 36412.
3. Создать TermPointToMme с адресом MME и сослаться на SctpEndpoint.
4. Включить TermPointToMme командой administrativeState=UNLOCKED.

## Проверка после настройки
Команда st sctp показывает состояние ассоциаций: состояние ESTABLISHED означает, что S1-MME установлен. Команда get TermPointToMme= operationalState должна вернуть ENABLED. Если состояние остаётся CLOSED, проверьте доступность MME по ICMP и совпадение портов.

## Типовые неисправности
Если ассоциация устанавливается и сразу разрывается, чаще всего виновато несовпадение PLMN в S1 Setup Request и в конфигурации MME. Если ассоциация не устанавливается вовсе, проверьте межсетевой экран: порт SCTP 36412 должен быть открыт в обе стороны. Частые повторные передачи указывают на слишком низкий rtoMin для реальной задержки канала.
